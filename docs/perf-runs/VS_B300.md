# MI300X vs NVIDIA B300 (Sol-H3 reference) — 2026-09-08

Internal. User-facing scoreboard: [`../PERFORMANCE.md`](../PERFORMANCE.md).

Apples-to-apples run against NVIDIA's published Sol-H3 numbers for a single
B300: 5 s video at **1344×768, 24 FPS** — Base H3 (50 steps) **129.898 s**,
Sol-H3 (4 steps) **13.745 s** (9.45× speedup, per NVIDIA's Sol-H3 benchmark).

Build: git `8118c71` (`H3_VERSION "0.11.0"` in `h3.h`; tree contains the
post-0.12.0 perf work, version string not yet bumped). MI300X (gfx942).

**Weight caveat.** Sol-H3 weights were not on hand; both local runs use the
**base MiniMax-H3** weights. Sol-H3 is a distillation of the same architecture,
so the 4-step run has **equivalent compute** to the official Sol-H3 4-step
benchmark — the timing comparison is valid, but visual quality would require
the distilled weights.

## Commands

```sh
# 4-step (Sol-H3 compute proxy)
./h3 --profile -d /mnt/doscratch/MiniMax-H3 \
  -p "A red fox walks through fresh snow in a pine forest. Medium tracking \
shot, natural winter light, realistic fur, soft footsteps and wind." \
  --width 1344 --height 768 --seconds 5 \
  --steps 4 --layers 50 --reuse 1 --seed 42 \
  -o outputs/b300-cmp-sol4.mp4

# 50-step (Base H3 match)
  --steps 50 --layers 50 --reuse 1 --seed 42 \
  -o outputs/b300-cmp-base50.mp4
```

Outputs verified with ffprobe: both **1344×768 @ 24 fps, 124 frames**
(5.17 s), matching the official benchmark configuration.
Artifacts: `outputs/b300-cmp-sol4.mp4`, `outputs/b300-cmp-base50.mp4`.

## Head-to-head

| Config | MI300X E2E | B300 (official) | Ratio |
|--------|-----------:|----------------:|------:|
| 4 steps (Sol proxy) | **93.0 s** | 13.745 s | **6.8×** |
| 50 steps (Base match) | **674.8 s** (11m15s) | 129.898 s | **5.2×** |

## MI300X breakdown (4-step run)

| Stage | Time |
|-------|-----:|
| DiT denoise (4 steps) | **51.98 s** (13.0 s/step; sdpa 40.9 s = 79%, linear 8.6 s) |
| Video VAE decode | 27.6 s (tiles 4×2 at 416 px) |
| Text encode + DiT load | ~10.5 s |

50-step denoise ≈ **634 s** (12.7 s/step — linear with the 4-step rate).
Peak VRAM **27.6 GiB** (192 GiB card → large headroom).

## Takeaways

- **Per-step efficiency**: MI300X ~13.0 s/step vs B300 ~3.44 s/step → **3.8×**.
  Theoretical BF16 peak gap is only ~1.7×, so the HIP port leaves roughly
  **2× on the table in the attention path** (sdpa is 79% of denoise).
- **Accounting caveat**: if NVIDIA's 13.745 s is denoise-only, the fair match
  is 52.0 s vs 13.7 s = **3.8×**; if it is E2E, **6.8×**. Same ambiguity
  applies to the 50-step figure (634 s vs 129.9 s = 4.9× denoise-only).
- **Internal distillation speedup**: on MI300X, 50 → 4 steps gives **7.3×
  E2E** (12.2× denoise-only, ≈ the 12.5× step ratio); NVIDIA reports 9.45×
  on B300. Sol's per-step overhead on B300 (~+32% vs Base) does not appear
  here since both local runs use base weights.
- VAE decode (27.6 s) is 30% of the 4-step E2E — at low step counts it, not
  the DiT, becomes the second bottleneck. Peak VRAM leaves room for larger
  VAE tiles / fewer splits.
