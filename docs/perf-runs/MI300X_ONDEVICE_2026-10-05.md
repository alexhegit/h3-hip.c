# MI300X (gfx942) — H3-OnDevice 480p / 5 s, with `--fbc`

2026-10-05. DORobot, AMD Instinct MI300X VF (`gfx942`), VRAM total
**191.69 GiB** (`205822885888`). Tree: local branch `mi300x-fbc` at
`fadfcda` (origin/main, “Record the gfx1151 on-device 5s fixture and add
opt-in --fbc”). Build: `make clean && make HIP_ARCH=gfx942 -j$(nproc) h3`.
Model: `/mnt/doscratch/MiniMax-H3`. No `H3_FP8_MLP` / `H3_INT8_MLP` /
`H3_GPU_SAMPLER` / `H3_INT8_VAE` overrides, so DiT stays default INT8.
Seed **42**.

`--fbc` from `fadfcda` compiled and ran on gfx942 with no ISA-specific
change. This ledger is the same fixture as
[`HALO_ONDEVICE_2026-10-05.md`](HALO_ONDEVICE_2026-10-05.md). It is not
the 2026-09-12 / 2026-09-18 `bench/` scoreboard (those rows are 864×480
or 1344×768, 15 s, 20 steps, 45 layers).

Workload: **832×480**, 24 fps, **124 frames**, **5.167 s**, **50 steps**,
**50 layers**, `--reuse 1`. Command:

```bash
./h3 --profile -d /mnt/doscratch/MiniMax-H3 \
  -p 'Cinematic push-in on a starship bridge: a captain in a high-collared navy tunic stands silhouetted at the observation window as a dreadnought armada charges its hyperdrives. A blinding flash, the bridge shudders, and the fleet is gone.' \
  --width 832 --height 480 --seconds 5 \
  --steps 50 --layers 50 --reuse 1 --seed 42 \
  -o outputs/mi300x-ondevice-p1-baseline.mp4
```

Lossy flags are separate arms. `--fbc` still uses `--reuse 1`. Quality is
FFmpeg `psnr` / `ssim` on the muxed H.264 streams and float32 PCM SNR
versus the dense MP4. Speed ratios are versus this machine’s dense E2E.

denoise **136.723 s**, audio VAE 0.519 s, video VAE 9.807 s (tiles 4×2 at
272 px). Denoise is **82%** of the 166.87 s process E2E. Peak live tensors
**22.657 GiB**. Attention calls **2500**. Output
`outputs/mi300x-ondevice-p1-baseline.mp4`: 832×480, 124 frames, 24 fps,
duration 5.167 s. md5 `66b7f67216918ba712b27a909052eb33`.

τ=1 blocks 2:50 keeps layers 0–1 dense. Exact KV tiles: τ=0.5 kept
**34.63%**, τ=1 kept **21.07%**. Linear barely moves (49.2 s dense,
49.6 s at τ=1); the Sol-Attn win is SDPA, 76.0 s → 37.5 s.

`--fbc` default `H3_FBC_REL=0.15`, head 2, tail 2. This run was **9 full /
41 skip** (full steps 1–2, 11, 22, 33, 41, 46, 49–50), the same step list
as the gfx1151 run. Attention calls 2500 → **491** (`9×50 + 41×1`).
Denoise other 6.085 s. Peak **23.254 GiB**. Denoise itself is **4.39×**
versus dense (136.723 / 31.177). Process E2E is only **3.13×** because
video VAE stays ~9.8 s and is a larger share of the shorter run. Video
PSNR/SSIM sit above both Sol-Attn arms and above token reduction. Audio
SNR is **1.29 dB** (err rms 0.0875, ref rms 0.10148279, 331776 samples),
below both Sol-Attn arms.

`--token-reduction` keeps 2500 attention calls, peak 22.660 GiB, and cuts
both SDPA and linear. Audio SNR **−4.26 dB** (err rms 0.1657): the
soundtrack diverges by more energy than the dense reference. On this
fixture TR is slower than `--fbc` and farther from the dense clip.

## Against the gfx1151 fixture and older MI300X rows

Same command on gfx1151 (`HALO_ONDEVICE_2026-10-05`): dense 3477.57 s,
`--fbc` 697.78 s (4.98×). This MI300X dense E2E is **20.8×** that Halo
dense time (3477.57 / 166.87). The `--fbc` E2E is **13.1×** the Halo
`--fbc` time (697.78 / 53.31). Skip schedule matches. Quality is versus
each machine’s own dense clip, so the dB figures are not a cross-machine
PSNR.

Spark’s published 480p ladder is a warm BF16 stack (baseline 710.6 s,
kernels + Sol-Attn τ=1 + first-block cache 181.3 s). This table is one
cold-ish HIP INT8 process per arm, including weight load. The MI300X
`--fbc` row is that cache alone, at **53.31 s**.

The older MI300X process E2E for 15 s no-TR was **213 s** (2026-09-18,
864×480, 20 steps, 45 layers). That is a different canvas, length, step
count, and layer count. It is not a row in the table above.
