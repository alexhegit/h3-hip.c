# MI300X — 1344×768 · 15 s dense SDPA A/B (2026-09-21)

Quality-path CDNA flash changes on `main` (`858288f` prefetch + `9f3899f`
P-tile LDS pad) vs the pre-prefetch kernel. Same prompt as
`bench/fox-15s.sh`, **no** `--token-reduction` / Sol-Attn / GPU sampler /
`H3_INT8_VAE`. AMD Instinct MI300X VF (`gfx942`), model
`/mnt/doscratch/MiniMax-H3`. Timed box worktree
`/mnt/doscratch/h3-hip.c-v012-retest`.

**Process E2E** is `/usr/bin/time` until `h3: wrote` the muxed MP4.
**Denoise** is `--profile` `H3 DiT Euler denoise`. **sdpa / linear** are
the denoise `op-classes` line.

## Command

```bash
./h3 --profile -d "$H3_MODEL" -p "$(cat fox-15s-prompt)" \
  --width 1344 --height 768 --seconds 15 \
  --steps 20 --layers 45 --reuse 2 --seed 42 \
  -o outputs/1kmp15.mp4
```

`--seconds 15` aligns to **362 frames / 15.083 s**. Canvas is the released
max (`768×1344` pixels). Output: H.264 + AAC, ~6.7 MiB.

| Binary | Kernel |
|--------|--------|
| `h3-sdpa-baseline` | pre-prefetch `h3_sdpa_bf16_mfma_d128` (`STAGES=1`, `sp` ld = `BK`) |
| `h3-sdpa-opt` | `9f3899f` (register K/V prefetch + `SP_LD = BK+8`) |
