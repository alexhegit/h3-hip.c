# MI300X vs published NVIDIA numbers — Prompt 1, 768p, 5 s

2026-10-07. One Instinct MI300X (gfx942, DORobot). This is not a row in
the 832×480 / fox-15s tables in
[`MI300X_COMPARE_2026-10-07.md`](MI300X_COMPARE_2026-10-07.md).

NVIDIA's published 768p workload is **1344×768**, 24 fps, **124 frames**,
**5 s**, **50 steps**, seed **0**. The prompt is Prompt 1 from the
[H3-OnDevice page](https://nvlabs.github.io/Sana/Sol-Engine/H3-OnDevice/),
which prints a compacted sentence and points the benchmark at
[`demo_prompt.json`](https://github.com/NVlabs/Sana/blob/sol-engine/models/minimax_h3/demo_prompt.json)
on the `sol-engine` branch. That JSON's `target.duration_seconds` is 10.
The RTX 5090 and H100 configs override it to 5 seconds
(`H3_DURATION_SECONDS=5`, `width=1344`, `height=768`, `steps=50`,
`seed=0`). This run uses that override.

Sources for the NVIDIA cells:

- [H3-OnDevice](https://nvlabs.github.io/Sana/Sol-Engine/H3-OnDevice/) — RTX 5090 ladder, warm, batch 1.
- [models/minimax_h3](https://github.com/NVlabs/Sana/tree/sol-engine/models/minimax_h3) — H100 row, and the same 5090 baseline / full-opt pair.

## What was timed here

Stock MiniMax-H3, default **INT8** DiT, full video VAE. No
`--fasth3-lora`, `--taeh3`, `--vsa`, `--fbc`, `--sol-attn`, or
`--token-reduction`. `--layers 50 --reuse 1`. Process E2E is
`/usr/bin/time` until the process exits (the log ends at `h3: wrote`,
then `time`).

```sh
./h3 --profile -d /mnt/doscratch/MiniMax-H3 \
  -p "$(cat prompt1.txt)" \
  --width 1344 --height 768 --seconds 5 \
  --steps 50 --layers 50 --reuse 1 --seed 0 \
  -o outputs/mi300x-prompt1-768p-5s-dense.mp4
```

`prompt1.txt` is the `prompt` field of `demo_prompt.json` (the
`integrated_multimodal_description`, `overall_soundscape`, and
`non_diegetic_music` blocks). Output checked with ffprobe: **1344×768**,
24 fps, **124 frames**, duration **5.175 s**, H.264 + AAC.
md5 `bd26744e1a951290b99fccc7ad311a88`. Log:
[`gfx942-2026-10-07-prompt1-768p-5s-dense.log`](gfx942-2026-10-07-prompt1-768p-5s-dense.log).

| phase | time |
|---|---:|
| text encoder | 3.482 s |
| DiT load | 3.785 s |
| Euler denoise | **623.543 s** |
| denoise SDPA / linear | 470.734 / 122.968 s |
| audio VAE | 0.519 s |
| video VAE | **34.366 s** |

Denoise peak **28.614 GiB**. Attention calls 2500 (50×50). Denoise plus

clock, so the warm-comparable number and the process number are close.

## Published NVIDIA times, same 768p · 5 s workload

NVlabs say these are warm runs, and that the table is a same-hardware
speedup, not a cross-GPU latency ranking. Full opt is Sol-Attn plus a
cross-step cache (TeaCache on the 5090 config). Their transformer and
VAE dtypes in the 5090 config are **BF16**. The H100 cell is **4 GPUs**.

| device | GPUs | baseline | full opt | their speedup |
|---|---:|---:|---:|---:|
| RTX 5090 | 1 | 1045.4 s | **231.2 s** | 4.52× |
| H100 | 4 | 81.47 s | **22.89 s** | 3.56× |

RTX 5090 ladder on the H3-OnDevice page, same 1344×768 · 5 s · 50-step job:

| stage | time | vs their baseline |
|---|---:|---:|
| baseline, unmodified reference | 1045.4 s | 1.00× |
| kernel optimization | 971.6 s | 1.08× |
| + Sol-Attn | 708.3 s | 1.48× |
| + cross-step cache | 231.2 s | 4.52× |

The same README also lists GB200×8 (27.21 → 6.88 s), RTX 4090×1
(2239.22 → 504.33 s), and A100×4 (217.32 → 61.28 s) at 768p · 5 s, plus
DGX Spark at **480p**, not 768p. Those rows were not re-measured here.

## Head-to-head

Compare the MI300X dense INT8 run with the published cells. Do not read
a dense 50-step time as if it were their full-opt stack.

| published cell | published time | MI300X denoise+decode 658.4 s | MI300X process 668.15 s |
|---|---:|---:|---:|
| RTX 5090 baseline, 1 GPU, BF16 | 1045.4 s | MI300X faster, 1.59× | MI300X faster, 1.56× |
| RTX 5090 + Sol-Attn | 708.3 s | MI300X faster, 1.08× | MI300X faster, 1.06× |
| RTX 5090 full opt | 231.2 s | 5090 faster, 2.85× | 5090 faster, 2.89× |
| H100 baseline, 4 GPUs | 81.47 s | 4×H100 faster, 8.1× | 4×H100 faster, 8.2× |
| H100 full opt, 4 GPUs | 22.89 s | 4×H100 faster, 29× | 4×H100 faster, 29× |

Three differences sit in every ratio:

- This MI300X number is **dense 50-step INT8**. The 231.2 s and 22.89 s
  cells are **Sol-Attn + cache**. `--fbc` and `--sol-attn` were not run
  on this 768p fixture.
- Their 5090 config is **BF16** weights. This run quantizes the DiT to
  **INT8** (default).
- The H100 row is **four GPUs**. The 5090 row and this run are one GPU.
