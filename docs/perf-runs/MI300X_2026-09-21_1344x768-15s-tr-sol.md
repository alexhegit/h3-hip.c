## Sequence length (issue #10)

This canvas is **109334** packed tokens (**1709** 64-token KV tiles).
864×480 · 15 s stays under 1024 tiles / 65536 tokens and uses the original
static LDS route tables. 1344×768 · 15 s used to abort:

```
h3: DiT head-major full attention: Sol-Attn sequence exceeds 65536 tokens
```

`--token-reduction` does not unblock that path: TR only halves spatial
width in **middle** DiT blocks; first/last layers still see the full
sequence.

The overflow path keeps the 1024-tile LDS kernels for shorter sequences
and launches a separate 8/32 instantiation with **dynamic shared** routing
tables when `n_blocks > 1024`. Cap is `H3_SOL_MAX_KV_BLOCKS_EXT` (4096
tiles / 262144 tokens). Keep-all (`H3_SOL_ATTN_TAU=-100`) matches dense
at 65664 tokens on gfx1151 and gfx942 (`H3_CHECK_SOL_ATTN=1`).
